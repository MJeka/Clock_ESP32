Профессиональное решение для умных часов на базе **ESP32**, **LVGL 8.3** и дисплея **ST7789**. Проект объединяет современный графический интерфейс, синхронизацию времени по NTP, прогноз погоды и удобную настройку через веб-интерфейс.

---

## ✨ Основные возможности

- 🖥️ **Графический интерфейс**: Построен на библиотеке **LVGL 8.3** (дизайн SquareLine Studio).
- ☁️ **Погода**: Модульная система получения данных (по умолчанию **Open-Meteo API**).
- ⏰ **Точное время**: Стандартная синхронизация **ESP32 NTP** (time.h) с поддержкой POSIX временных зон.
- 🌓 **Ночной режим**: Автоматическое управление яркостью подсветки (ШИМ) по расписанию.
- 🌐 **Web-интерфейс**: Настройка WiFi, выбор города с координатами и параметров яркости.
- 🛜 **Captive Portal**: Режим точки доступа (AP) для начальной настройки при отсутствии сети.
- 📲 **OTA**: Беспроводное обновление прошивки по Wi-Fi.

## 📂 Структура проекта (Архитектура)

Проект разделен на логические модули для удобства поддержки и расширения:

### 📁 `src/` (Исходный код)
- **`main.cpp`** — Ядро системы. Инициализация аппаратной части, управление состояниями (WiFi, AP, STA), обработка таймеров и обновление UI.
- **`provider_om.cpp`** — Реализация провайдера погоды для **Open-Meteo**. Выполняет HTTP-запросы и парсинг JSON.
- **`ui_weather.cpp`** — Карта соответствия погодных кодов (WMO) и визуальных ресурсов (иконок) LVGL.

### 📁 `include/` (Заголовки и конфигурация)
- **`weather_provider.h`** — Абстрактный интерфейс для погодных служб. Позволяет легко добавить другой источник (например, WeatherAPI или OpenWeather) без изменения основного кода.
- **`weather_types.h`** — Унифицированная структура `weather_data`, через которую данные передаются в UI.
- **`cities_db.h`** — База городов в `PROGMEM`. Формат: `"RU|UA|EN|Code|Lat|Lon"`. Передается в Web-интерфейс как JSON для автодополнения.
- **`wifi_logic.h`** — Логика работы с сетью, Web-сервером, DNS (Captive Portal) и OTA.
- **`web_pages.h`** — HTML/CSS/JS составляющие веб-интерфейса настроек.
- **`secrets.h`** — Конфиденциальные данные (настраивается пользователем).

### 📁 `lib/ui/`
- Графические компоненты и ресурсы, экспортированные из **SquareLine Studio**.

## 🌤️ Модуль Погоды: Как это работает

Система использует паттерн "Адаптер" для работы с погодными данными:

1. **Запрос**: `main.cpp` каждые 15 минут вызывает `weather_provider.fetch_current()`.
2. **Получение**: Провайдер (`ProviderOM`) делает HTTP GET запрос и парсит ответ с помощью `ArduinoJson`.
3. **Унификация**: Данные упаковываются в структуру `weather_data`:
   - `temperature` (float)
   - `humidity` (int)
   - `pressure_mm` (int) — автоматически конвертируется из hPa в мм рт. ст.
   - `wmo_code` (int) — стандартный код погоды.
   - `is_day` (bool) — время суток для выбора иконки.
4. **Отображение**: `main.cpp` передает код в `update_weather_icon()`, которая по карте из `ui_weather.h` выбирает нужный ресурс (`ui_img_...`) и обновляет объект на экране.

## 🔌 Подключение оборудования

### 1. Дисплей (ST7789)
| Пин дисплея | Пин ESP32 | Описание |
| :--- | :--- | :--- |
| **VCC** | 3.3V | Питание |
| **GND** | GND | Земля |
| **SCL (SCLK)** | 18 | SPI Clock |
| **SDA (MOSI)** | 23 | SPI Data |
| **RES (RST)** | 33 | Reset |
| **DC** | 27 | Data / Command |
| **CS** | 5 | Chip Select |
| **BLK (BL)** | 22 | Подсветка (PWM) |

### 2. Тачскрин (XPT2046)
| Пин тача | Пин ESP32 | Описание |
| :--- | :--- | :--- |
| **TSCK** | 12 | SPI Clock |
| **TMISO** | 13 | SPI MISO |
| **TMOSI** | 15 | SPI MOSI |
| **TCS** | 14 | Chip Select |
| **EN** | 3.3V | Питание Touch |

> [!NOTE]
> Все настройки пинов и частот SPI находятся в файле `platformio.ini` в блоке `build_flags`.

## 📡 Веб-интерфейс

Если WiFi не настроен, ESP32 создаст сеть `ESP-CLOCK-XXXX`. 
На странице настроек (`192.168.4.1`):
1. **Выбор WiFi**: Сканирование доступных сетей.
2. **Выбор города**: Встроенный поиск по базе `cities_db.h`. При выборе города **автоматически** подставляются его координаты (Lat/Lon) для точного прогноза погоды.

## 📡 OTA

1. **Обновление по воздуху (OTA)**:
   Чтобы прошить удаленно, раскомментируйте строки в `platformio.ini`:
   ```ini
   upload_protocol = espota
   upload_port = Clock-ESP32.local
